On My Disk Embedded Client
==========================
Integration notes

1. Directories structure
------------------------

   Package files should be placed to /usr/ folder on the target.
   
   /opt/bin/onmydisk  - application binary	
   /opt/bin/wsdd - Web Service Discovery (WSD) script. Publishes device in Network Neighbourhood (optional)	
   /etc/onmydisk/onmydisk.conf - configuration file
   /etc/init.d/onmydisk - OnMyDisk start script
   /etc/init.d/wsdd - WSD start script


2. Key configuration parameters	
-------------------------------
   [FileNode]
   ;Location where persistent data (ssl key, certificate, links db) should be stored
   ;By default all data is stored in /etc/onmydisk, but you can place it to other persistent location 
   ;ProfilePath=<path/to/stored/data>

   ;Web UI port. Use devce key (<ProfilPath>/device.id) to login
   Port=8081  
   

   ;Statically mounted shares. 
   ;Used to share partitions/directories that are statically mounted
   ;Label=Partition/Directory/Path
 
   [Shares]
   USB=/var/usbmnt/sda1

   [Network]  
   ;Login with device key (no user account needed)
   keyLogin=true
   
   ;Server
   host=onmydisk.net
  
   ;Connection port
   port=9000
  
   ;REST API port, should be 443 for deployment
   restPort=443
  
   ;Rest API url
   restUrl=https://onmydisk.net/pki

   ;Web socket port used for dynamic notifications of Web UI. 
   ;Should be 8899 for embedded devices
   wsPort=8899

   ;Connect on start
   connect=true	

3. Command line interface
-------------------------
   Could be used by other applications as IPC

   Usage: onmydisk [options]
   On My Disk client filesystem access service

   Commands:
   -h, --help                 	 Displays this help.
   -v, --version              	 Displays version information.
   -a, --add-share <label:path>  Add share.
   -r, --remove-share <label>    Remove share. 
   -d, --disconnect              Disconnect. External access disabled
   -c, --connect                 Connect. External access enabled
   -q, --quit                    Quit.

   Commands --add-share and --remove-share can be used for addiing/removing shared folders 
   dynamically  right after mounting/unmounting partitions in the host firmware.

4. Autogenerated persistent data
--------------------------------
   These files are created dynamically and stored in <ProfilePath>:

   <ProfilePath>/device.id  		device key, used as login key,
   <ProfilePath>/ssl/user.key  		private key of SSL certificate,
   <ProfilePath>/ssl/user.crt  		SSL certificate,
   <ProfilePath>/ssl/rootCA.crt  	Server CA certificate,
   <ProfilePath>/share.db		Shared links database (sqlite)

5. Themeing 
--------------------------------
   [General]
   AppTitle=InnShare 			Application title in browser
   Company=InnBox 			Company info in html template header
   Slogan=World in a Box 		Slogan in html template header
   Server=storage.innbox.net		Server address for shared url-s
